# Data Grid Master

Build a feature-complete Zoho CRM DataTable clone with rich interactive sample data. Include signature Zoho CRM list view features:
1. View switchers: List View, Kanban / Stage Board, and Split (Master-Detail) View.
2. Left filter drawer with saved system views ("All Leads", "My Open Leads", "Unread Leads", "Converted") and a custom criteria filter builder.
3. Advanced column management: show/hide columns modal, drag-and-drop reordering, and sticky/frozen left columns.
4. Inline cell editing directly in the grid (names, company, lead status dropdown, lead source, email, rating, phone).
5. Row selection with a floating bulk action bar: Mass Update, Delete, Export (CSV), and Assign Owner.
6. Display density toggle (Compact, Standard, Comfortable), quick search, multi-column sorting, and configurable pagination (10, 20, 50, 100 per page).
7. Zoho CRM design aesthetic: clean borders, status badges, avatar chips, row hover actions, and polished action toolbars.
